Lateef (`Lateef-*.woff2`) is the website's Sindhi typeface, loaded by `styles.css`.

The other fonts are used by `scripts/build-og.py` to draw the link-preview card (the website itself loads them from Google Fonts):

- Lateef, Great Vibes, Alex Brush, Cormorant Garamond: SIL Open Font License 1.1 (https://openfontlicense.org).
